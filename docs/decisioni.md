# Decisioni di progetto

- Progetto individuale, ambito sanitario: passwordless (FIDO2) + blockchain; prove a conoscenza zero descritte come estensione futura.
- Ethereum + Solidity (Hardhat, OpenZeppelin); Fabric e Go solo come confronto nella relazione.
- Backend Node.js con TypeScript.
- Dati: solo cartelle cliniche sintetiche.
- Anonimato del medico contro responsabilità nell'audit (estensione ZKP): verso la catena il medico compare solo come nullifier, diverso per ogni rapporto di cura; la struttura lo identifica tramite il registro cifrato degli accessi.
